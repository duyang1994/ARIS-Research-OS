# RESULT REVIEW HEADER

Reviewing any agent report must produce these fields **before** narrative
interpretation.

```text
PROJECT IDENTITY:          PASS/FAIL
SCIENTIFIC FINGERPRINT:    PASS/FAIL
INPUT LINEAGE:             PASS/FAIL
FREEZE STATE:              PASS/FAIL
IMPLEMENTATION:            PASS/FAIL
RESULT VALIDITY:           PASS/FAIL
REPRODUCIBILITY:           PASS/FAIL
HUMAN DECISION REQUIRED:   YES/NO
```

Only after these fields may narrative interpretation begin.
