# HUMAN PRE-FLIGHT HEADER

Keep this header to approximately 10-15 lines. The human should only need to
inspect this header, not hundreds of lines of implementation instructions.

```text
PROJECT:                  PLACEHOLDER
CANONICAL ROOT:           PLACEHOLDER
TASK:                     PLACEHOLDER
READ SOURCES:             PLACEHOLDER
WRITE TARGET:             PLACEHOLDER
SCIENTIFIC UNIT:          PLACEHOLDER
ANCHOR:                   PLACEHOLDER
WINDOW:                   PLACEHOLDER
FEATURE SPACE:            PLACEHOLDER
DESTRUCTIVE OPERATIONS:   NONE
FOREIGN PROJECTS FORBIDDEN: YES
```

Any field that is not routine must be explicitly flagged for human attention.
