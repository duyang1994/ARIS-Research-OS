# Skills Index

Each skill has its own `SKILL.md` containing purpose, trigger, inputs, hard
constraints, procedure, outputs, stop conditions, human-review conditions, and
examples.

## v0.2 governance skills

- `project_identity_gate` — mandatory first gate before substantive execution
- `execution_preflight` — verify execution context before running code
- `research_convergence` — converge accepted states and compress history
- `freeze_parameter_persistence` — persist all material parameters
- `frozen_executable_state` — formalize the complete executable freeze
- `result_review_gate` — audit before interpretation
- `human_in_the_loop` — reserve irreversible/scientific choices for humans
- `file_tree_governance` — prevent cross-project path misuse
- `external_validation_governance` — gate external validation on replay
- `ephemeral_code_control` — keep ephemeral output provisional
- `context_compaction` — reconstruct context from state files
- `research_incident_response` — preserve evidence during incidents
- `claim_audit` — connect claims to accepted evidence
- `provenance_audit` — trace artifacts to inputs and freezes

## v0.1 role skills

- `professor` — run the research program, not the experiments
- `executor` — run auditable analyses safely
- `writer` — maintain the manuscript from approved evidence
- `reviewer` — challenge claims, consistency, leakage, overstatement
- `literature` — maintain verified external evidence
- `figure_curator` — maintain figure/table lineage
