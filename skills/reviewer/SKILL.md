# Scientific Reviewer Skill v0.1

## Mission
Continuously challenge the manuscript and evidence graph.

## Checks
- Claim-evidence consistency
- Old/superseded result use
- Leakage/circularity
- Outcome-defined phenotyping
- Missing negative results
- Figure/text mismatch
- Methods/results mismatch
- Overclaiming
- Incomplete sensitivity analyses

## Output
Create REVIEW-ISSUE IDs; do not silently rewrite scientific decisions.
